# F1.5 — Lobby y pantallas con el layout del UI kit de Funtico

Del kit se toma **solo el layout** (qué va dónde, tamaños y flujo). Estilo = el nuestro (`src/funtico/ui.ts`: fondo
#06060c, amarillo, lilas, bordes rectos, fuente Press Start 2P) y arte de las escenas del juego. Sin `$ZERO`, sin NFT.
Maqueta previa: `/var/tmp/funtico/f1-5/maqueta/{lobby-v,lobby-h,pantallas-v}.png` (generador `gen.py` al lado).

## Fuera y por qué

- REWARDS (Hall of Fame), Tournaments/Rooms/1vs1 (lobby), ROOMS/TOURNAMENTS (Mis resultados), saldos y monedas de la
  barra, DEVELOPER NOTE: el juego no los tiene (encargo). El saldo de Tico no se muestra: el SDK no lo da.
- MONTHLY: el SDK sí distingue el periodo (`GetHallOfFame(HallOfFamePeriodMode)`) y el simulado filtra por mes: no
  hace falta nota.
- Barra superior en `CampaignMapScene`: el componente es reutilizable (`new TopBar(scene, { here })` + `layout(w)` +
  `bounds()`), pero no se puso aún para no chocar con la rama de Campaign en curso (F3.2b) ni con el BACK del mapa.
- Música iMUSE de Triage: la conecta F1.4 a `getMusicVolume()`/`onSettingsChange` al juntar las ramas.
- Textos ES/JA: otro checkpoint.
