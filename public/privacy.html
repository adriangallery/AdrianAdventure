ZEROadventure II — Privacy Policy

Last updated: April 2026

Overview

ZEROadventure II is a point-and-click adventure game. We respect your privacy and collect the minimum amount of data necessary for the game to function.

Data We Collect

Game Save Data

Your game progress (inventory, visited scenes, achievements) is saved locally on your device using browser storage (localStorage). This data never leaves your device unless you explicitly opt in to cloud saves by connecting a wallet.

Wallet Address (Optional)

If you choose to connect a blockchain wallet, we store your public wallet address to:

  • Sync your save data across devices via our cloud save server
  • Check your token holdings for optional in-game features
  • Display your ENS name on the leaderboard (if applicable)

Connecting a wallet is entirely voluntary. The full game is playable without it.

Session Authentication

When you connect a wallet, you sign a one-time message to authenticate your session. This signature is used only to authorize save operations and is not stored permanently.

Data We Do NOT Collect

  • Personal information (name, email, phone number)
  • Device identifiers or advertising IDs
  • Location data
  • Usage analytics or tracking data
  • Private keys or seed phrases (we never have access to these)

Third-Party Services

  • Alchemy API: Used to read public blockchain data (NFT ownership). Alchemy receives your public wallet address when checking token balances. See Alchemy's Privacy Policy.
  • WalletConnect: Used for wallet connection on mobile. See WalletConnect's Privacy Policy.

Cloud Save Server

Our cloud save server stores game progress data associated with your public wallet address. All data is transmitted over HTTPS. You can delete your cloud saves at any time from within the game.

Children's Privacy

ZEROadventure II is not directed at children under 13. We do not knowingly collect personal information from children.

Data Deletion

You can delete your local save data by clearing your browser/app storage. Cloud save data can be deleted from within the game's save menu.

Changes to This Policy

We may update this policy from time to time. Changes will be posted on this page with an updated date.
